# Sales Person Target & Dealer Target with Delivery Schedule Add-On

## Overview

The Sales Person Target & Dealer Target with Delivery Schedule Add-On is developed for SAP Business One to manage sales targets, dealer targets, and planned delivery schedules efficiently. This add-on helps organizations monitor target achievement, track dealer performance, and improve delivery planning.

## Key Features

### 1. Sales Person Target Management

* Define monthly, quarterly, and yearly sales targets.
* Assign targets to individual sales employees.
* Monitor target achievement status.
* View target vs. actual sales analysis.

### 2. Dealer Target Management

* Define sales targets for dealers/distributors.
* Maintain target history by period.
* Track dealer performance against assigned targets.
* Generate dealer target reports.

### 3. Delivery Schedule Management

* Create delivery schedules against dealer orders.
* Manage planned delivery quantities and dates.
* Track pending and completed deliveries.
* Monitor delivery performance.

### 4. Approval Workflow

* Submit target records for approval.
* Multi-level approval support.
* Approval history tracking.
* Automatic status updates.

### 5. Reporting & Analytics

* Sales Person Target Report.
* Dealer Target Report.
* Target Achievement Analysis.
* Delivery Schedule Status Report.
* Performance Dashboard.

## Business Process Flow

1. Create Sales Person Target.
2. Create Dealer Target.
3. Submit for Approval.
4. Approver Reviews and Approves.
5. Create Delivery Schedule.
6. Execute Deliveries.

## Installation

### Prerequisites

* SAP Business One Version 10.0 or above
* SAP Business One DI API
* SAP Business One UI API
* Microsoft .NET Framework 4.8 or later
* SQL Server / SAP HANA

### Installation Steps

1. Install Add-On package.
2. Register Add-On in SAP Business One.
3. Assign user authorizations.
4. Configure approval templates.
5. Restart SAP Business One.
